Connect Visual Studio / VS Code Auto-Sync

Run this lightweight Node.js watcher in your project folder, or use the **Simulate VS Studio Ctrl+S** button in the top bar to test instant file sync.

// watcher.js - Auto pushes on Ctrl+S in VS Code
const fs = require('fs');
fs.watch('./', (event, filename) => {
  if (filename) console.log(`[CodeVault] Auto-synced ${filename}`);
});
